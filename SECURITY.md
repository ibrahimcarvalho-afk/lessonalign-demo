# Publication boundary

This repository is intentionally public and contains **only** static, sanitized demonstration artifacts.

Allowed:
- `PUBLIC-*` fixtures;
- static HTML/JSON;
- GitHub Pages workflow.

Forbidden:
- real operational or institutional corpus;
- names or personal data;
- internal documents, coordinates, SOPs, credentials or tokens;
- writable APIs or secrets.

The private `lesson-align` repository remains the development source of truth.
